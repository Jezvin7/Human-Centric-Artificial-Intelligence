Project 2: Explainability

This project uses the Palmer Penguins dataset. The goal is to predict the penguin species using interpretable models and compare accuracy with model complexity.

Dataset Overview

The dataset contains eight features:

  • species
  • island
  • sex
  • year
  • bill length mm
  • bill depth mm
  • flipper length mm
  • body mass g

The target feature is species, which has three classes: Adelie, Gentoo, and Chinstrap.

PDP and ALE are computed for the currently selected model type and λ value. For logistic regression, class probabilities are differentiable, so partial derivatives can be computed analytically. For decision trees, the prediction function is piecewise constant and not smoothly differentiable at split thresholds, so ALE must be estimated using discretized feature intervals. In this interface, ALE is computed with a model-agnostic finite-difference discretization for both model types.
